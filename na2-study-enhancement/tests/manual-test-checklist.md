# 수동 검증 체크리스트

- [ ] index.html을 Chrome/Edge에서 열 수 있다.
- [ ] 이론 주제 전환 후 학습 완료 기록이 저장된다.
- [ ] 필기 문제에서 정답 제출 시 100점, 오답 제출 시 0점이 기록된다.
- [ ] 제출하지 않고 정답 제출을 누르면 안내 메시지가 표시된다.
- [ ] 오답 문항이 오답노트에 나타난다.
- [ ] 오답 문항을 다시 풀어 맞히면 미해결 오답 수에서 제외된다.
- [ ] 페이지 새로고침 후 기록이 유지된다.
- [ ] 대시보드의 전체/영역별 정답률과 최근 7일 정답률이 갱신된다.
- [ ] 기록 필터가 정상 동작한다.
- [ ] JSON 내보내기 후 가져오기로 기록을 복원할 수 있다.
- [ ] 잘못된 JSON 파일은 오류 안내를 표시한다.
- [ ] 기록 초기화 확인 후 저장 기록과 오답 상태가 초기화된다.
- [ ] 모바일 폭에서 탭, 문제 선택지, 기록 표가 사용 가능하다.
