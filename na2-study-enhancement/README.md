# NA2 학습 대시보드 확장 프로토타입

네트워크관리사 2급 학습을 위해 **이론 / 필기 / 실기**를 구분하고, 오답노트·브라우저 로컬 기록·점수 기반 학습 분석을 제공하는 정적 웹 앱입니다.

## 실행 방법
1. ZIP을 압축 해제합니다.
2. `index.html`을 Chrome 또는 Edge에서 엽니다. 별도 설치나 서버가 필요 없습니다.
3. 문제를 풀면 점수, 오답 상태, 영역별 정답률, 최근 7일 추이가 브라우저에 자동 저장됩니다.

## 구현 기능
- 이론 주제별 개념·핵심 체크리스트·학습 완료 기록
- 필기 문제, 주제 필터, 미풀이/오답 우선 보기
- 실기 영역 분리: 작업형 / 실습형 / 단답형·객관식
- 제출 즉시 채점, 정답·해설 표시
- 마지막 제출이 오답이면 오답노트에 추가, 다시 맞히면 해결
- 전체/영역별 정답률, 오늘 풀이 수, 최근 7일 정답률
- 최근 7일 정답률 막대 시각화, 취약 주제 추천
- 학습 기록 표와 영역/결과 필터
- JSON 백업 내보내기 및 가져오기
- 모바일 반응형 레이아웃

## 데이터 저장과 주의사항
- 저장 키: `na2_learning_dashboard_v1`
- 기록은 현재 브라우저의 `localStorage`에 저장됩니다. 다른 브라우저·PC와 자동 동기화되지 않으므로 백업을 권장합니다.
- 현재 포함된 문항은 **기능 확인용 샘플 문항**입니다. 원본 저장소의 900개 필기 문항이나 검수된 실기 문제은행을 자동으로 복제한 것이 아닙니다.
- 브라우저에서 정답 데이터가 보일 수 있으므로 감독 시험/시험 보안 용도로 사용하지 마세요.
- 이론 학습 완료 점수는 학습 활동 점수이며, 문제 정답률 계산에서는 제외합니다.

## 원본 NA2-study 저장소에 통합할 때
이 프로토타입은 원본 파일을 덮어쓰지 않는 독립형 앱입니다. 원본 React/Vite 프로젝트에 통합하려면 다음을 수행해야 합니다.

1. `src/app.js`의 `questions` 배열 대신 원본 콘텐츠 JSON을 읽도록 어댑터를 작성합니다.
2. `localStorage` 키와 데이터 스키마를 원본의 `na2_study_learning_v1`, `na2_study_written_v1`, `na2_study_cabling_v1`, `na2_study_practical_v1`와 충돌하지 않도록 정리합니다.
3. 원본 라우팅, 기존 기록 포맷, 디자인 시스템에 맞게 컴포넌트를 분리합니다.
4. `npm test`, `npm run build`, 저장/복원/오답 해결 회귀 테스트를 수행한 뒤 별도 브랜치로 통합합니다.

## 파일
- `index.html`: 앱 UI
- `src/style.css`: 반응형 스타일
- `src/app.js`: 문항 데이터, 채점, 로컬 저장, 기록/통계
